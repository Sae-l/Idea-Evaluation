# Cheapest build environment (tool-agnostic; use what the user already has)
Prefer tools and subscriptions already available, free tiers and open source. Check cost before recommending paid tools.

| Idea type | Cheap route |
|---|---|
| Software / data | code editor + AI assistant, git hosting, free static/app hosting tiers, smallest model that works, text instead of full documents |
| Electronics | open-source EDA and firmware tooling, existing dev boards, low-volume PCB services; search open designs first |
| Mechanical | free CAD, cardboard/wood mock-up, then makerspace or print service |
| Content / media | existing AI and design tools, free editors, cloud storage; verify per-use costs |
| Service / retail | spreadsheet, free listing/profile, simple form for pre-orders, one pilot customer |
| Physical consumer product | contract manufacturer or white label instead of own production |
| Large / cross-border project | written plan, local business advisory, grants, small-scale pilot first |
